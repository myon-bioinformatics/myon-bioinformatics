Markdown → PPTX ベンチマーク

原稿と計測CLIを同じフォルダーに保存し、Marp CLI と Ironmate のある環境で実行します。成果物は slides.pptx と benchmark.json です。

 計測CLIを保存 · Ironmate の変換手順

python pptx_bench.py slides.md --ironmate ../Ironmate --out result


完成したPPTXの見た目も確認するには --preview を追加します（LibreOffice・Poppler使用）。各ページのPNGと全ページのPDFが生成されます。
原稿の最初の表を編集可能なPowerPoint表として追加するには、空けておいたスライドの番号を --table-slide 2 のように指定します。
