① ケース定義 → ② 有効・無効・辞退を記録 → ③ 同条件で比較 → ④ クラス別に回帰分析 → ⑤ 採用条件を判定

有効：圧縮を適用した結果。無効：圧縮しない対照。辞退：安全に圧縮できず元の履歴を保持。未測定や失敗を辞退に混ぜません。

指標の定義

クラス別精度 = 正解数 / 判定可能数。 辞退率 = 辞退数 / 圧縮を試みた数。 回帰 = 無効で成功し、有効で失敗した同一ケース。

辞退、未実行、判定不能、エラーはそれぞれ分離。分子・分母と対象条件を保存し、圧縮可能ケース限定の削減率と全ケースの削減率を分けます。
